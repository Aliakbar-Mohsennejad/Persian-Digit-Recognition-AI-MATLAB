# Persian Digit Recognition using MATLAB

This repository contains a MATLAB-based implementation for reading and visualizing a handwritten Persian digit dataset stored in `.cdb` format. This project was part of the **Artificial Intelligence** course in the 7th semester of undergraduate electrical engineering studies.

The main purpose of this work was to become familiar with how AI models interact with real datasets, particularly in MATLAB. It includes structured file parsing, preprocessing of image data, and presentation of examples for visualization and initial understanding. The dataset used here is a well-known collection of Persian handwritten digits.

---

## Features

- Full binary and grayscale parser for `.cdb` files
- Count and summary of digit frequency
- Visualization of one sample per digit (0–9)
- Fully commented and organized MATLAB code
